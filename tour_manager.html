Tour Manager

Take a tour plan from the Tour Planner and work out the logistics: pickups, drive times, overnight stops and a run sheet.

How this works

The Tour Planner decides where and when; the Tour Manager works out how you get there. Build your tour in the planner, press Open in tour manager (or save the plan file and open it here). Add pickups if you're collecting people, and the run sheet shows each day's legs with miles and drive times. If a leg to tomorrow's gig is long, it suggests a Premier Inn or Travelodge up to your chosen drive time after the gig, towards the next one. Everything you add is saved into the plan file with Save plan with logistics, and the planner ignores it. Nothing here is a booking, and drive times are estimates unless you fetch real ones.
