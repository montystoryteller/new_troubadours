How the New Troubadours events data fits together

The site keeps its listings in one data file. It is organised into types of record, such as performers, venues and tours, and records point to each other instead of repeating details. Use the map to see the connections, or the field guide to see what each record holds.

Each arrow means “points to”. For example, a tour date points to a venue, so the venue’s address is stored once and every event there can use it. Clicking a box highlights its connections and lists them here.

* = needed for the record to work. Coloured tags switch the diagram and card to the record they point to. Most other fields are optional.

Dates are written DD/MM/YYYY. Every performer, venue, club and so on has a short id, such as daniel-morden. That id is what other records use to refer to it.
